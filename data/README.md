# Local data directory

Place manually downloaded datasets, licensed fonts, reviewed lexicons, generated images, and derived manifests here. This directory is ignored by Git so real prescription images and other local data are not committed.

Keep the dataset's original license/readme with your local copy. Before use, check `../DATA_SOURCES.md`, retain any required attribution, and do not put patient-identifiable data here unless it has been properly de-identified and its use is authorized.
